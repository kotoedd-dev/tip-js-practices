## 3. Исправление Эксперимента 2 (Стрелочная функция)
* **Исходная причина ошибки:** Фигурные скобки создали полноценное тело функции, требующее явного написания возврата.
* **Исходный результат:** `undefined` (тип: `undefined`).
* **Исправленный результат:** `16` (тип: `number`).
* **Вариант исправления в коде:**
```javascript
const square = (value) => value * value; // убраны фигурные скобки для неявного возврата
```
