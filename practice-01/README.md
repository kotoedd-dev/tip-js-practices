## 4. Задание 1: Различие результатов в двух средах
По результатам выполнения скрипта `hello.js` зафиксировано следующее различие:
* **В консоли браузера:** вывод строки `Тип document: object`. Это происходит потому, что в браузере объект `document` встроен по умолчанию и отвечает за работу с веб-страницей (DOM).
* **В терминале Node.js:** вывод строки `Тип document: undefined`. В среде Node.js на компьютере графический интерфейс и веб-страницы отсутствуют, поэтому объект `document` там не существует.

## 7. Отладка

### Таблица результатов отладки

| Параметр | Исходный результат | Исправленный результат | Причина ошибки и её исправление |
| :--- | :---: | :---: | :--- |
| **Выполнено:** (`completedTotal`) | `"32"` | `5` | **Причина:** Значения были объявлены как строки `"3"` и `"2"`. Оператор `+` выполнил конкатенацию текста.<br>**Исправление:** Удалены кавычки, переменные переведены в числовой тип. |
| **Осталось:** (`remainingTasks`) | `-24` | `3` | **Причина:** Из строки `"8"` вычиталась строка `"32"`. Произошло автоматическое приведение типов, вычитание `8 - 32` дало отрицательное число.<br>**Исправление:** После исправления типов вычисляется корректная разность чисел `8 - 5`. |
| **Контрольная сумма:** (`controlSum`) | `6` | `10` | **Причина:** В условии цикла стояло строгое ограничение `taskNumber < 4`. Цикл выполнял всего 3 итерации (`1 + 2 + 3`).<br>**Исправление:** Условие изменено на `taskNumber < 5`, что добавило 4-ю итерацию (`1 + 2 + 3 + 4`). |

### Иллюстрация работы с точкой останова
1. Точка останова была установлена в браузере Microsoft Edge DevTools на вкладке **Sources** (Источники) кликом по номеру строки вычисления переменной `completedTotal`.
2. Это позволило приостановить выполнение скрипта до завершения всех операций и пошагово отследить в панели **Scope** (Область видимости), как текстовые строки `"3"` и `"2"` ошибочно склеиваются в `"32"`.
