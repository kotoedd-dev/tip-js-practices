## 2. Описание и структура проекта
Веб-приложение для динамического управления списком задач через DOM и обработку событий.

**Ключевые файлы:**
* `index.html` и `styles.css` — каркас и оформление интерфейса.
* `src/data.js` — демонстрационные и индивидуальные наборы данных.
* `src/task-service.js` — расчет статистики и иммутабельные операции.
* `src/task-selectors.js` — логика фильтрации списков задач.
* `src/task-view.js` — генерация DOM-карточек и рендеринг интерфейса.
* `src/main.js` — подписка на события, клики, фильтры и общее управление.
